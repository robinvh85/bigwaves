# bigwaves

Crypto trading automation (EMA1D-EXIT, DCA) on Binance: Go + SQLite backend, React frontend,
shipped as one binary.

```bash
cp deploy/.env.example .env   # set DEV_USER_EMAIL for local login without Auth0
make dev                      # http://localhost:5173
```

See `CLAUDE.md` for commands and conventions, `.claude/plans/` for the roadmap.
